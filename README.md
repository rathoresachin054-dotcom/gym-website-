# KING KONG GYM

A modern and responsive gym website built for King Kong Gym, Jaipur.

The website provides information about gym services, training programs, facilities, and contact details.

## Pages

- Home
- Services
- Gallery
- Contact

## Features

- Responsive design
- Modern black and orange theme
- Hero section
- Gym highlights
- Services cards
- Gallery section
- Testimonials section
- Contact form
- Fitness CTA section
- Hover and focus states
- Mobile-friendly layout

## Technologies Used

- HTML5
- Tailwind CSS
- Git
- GitHub
